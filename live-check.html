LIVE CHECK

Is today's live data whole enough to trust?

This project asks whether NYC restaurants in different boroughs have different odds of recovering an A grade after a health violation — a question that only gets a trustworthy answer if it is checked against every inspection record NYC has published, not a partial slice of them. This page runs that one check, right now, against the live feed: does the row count still look like the complete record set, or has something come back short?

The stakes are not hypothetical. An earlier version of this project pulled data in a way that silently stopped early and produced a confident, wrong-looking result — see README.md's "Reproducing this" section for the full story. This page exists so a partial pull gets caught here, before it can feed a calculation, rather than discovered later the way it was the first time.

Preparing to check the live feed…

This page checks row-count completeness first, automatically. Once that check passes, a second step below lets you pull the complete live table into your own browser and recompute the borough-odds finding against it, flagging any borough whose result crosses the conventional 0.05 significance line relative to the published baseline. A passed completeness check on its own still says only that the feed looks whole enough to compute from safely — not that the borough-gap finding holds; the recompute step is what actually checks that.

Data: NYC DOHMH Restaurant Inspection Results, via NYC Open Data. Built during week 6 of enrollment in Pursuit's AI Native program.
